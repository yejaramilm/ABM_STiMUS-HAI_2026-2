# ABM_STiMUS-HAI_2026-2
Repository for updated model of STiMUS-HAI which introduces probabilistic rules.

STiMUS-HAI is an agent-based model of human-AI collaboration on shared digital artefacts, in which contributors coordinate through stigmergy and mutualism. Agents contributors choose artefacts with a deterministic rule that always selects the most attractive option (Greedy criteria), an assumption that departs from the Ant Colony Optimization literature on which the model is based and causes all agents to converge on a few artefacts. This study works over STiMUS-HAI , first documents the model with the ODD+D protocol and introduces two probabilistic selection rules: the random proportional rule of Ant System and the pseudo-random proportional rule of Ant Colony System. After verifying that the modified model reproduces the original exactly, the three rules were compared in a full-factorial replication of the original experiment (10,800 runs, 500 ticks) and in a long-horizon experiment (3,000 ticks).
We found that the probabilistic rules reduce the concentration of edits and prevent the lock-in produced by the deterministic rule. Their effect on completion depends on the horizon: the deterministic rule completes more artefacts in short runs, but lock-in slows it down and the probabilistic rules catch up over time.
